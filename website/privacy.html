Privacy policy

Effective August 29, 2026 · Publisher: Constantin Knab · Contact: Quiet Browse support

Purpose

Quiet Browse reduces high-stimulation browsing through reversible presentation controls, social-feed controls, instant paging, optional grayscale by local time, and an optional local adult-site blocker. Built-in profiles operate on the disclosed social and shopping hosts; other presentation profiles operate only after the user authorizes them.

Information processed on the device

The extension uses the current page's host, document structure, limited static labels and text in candidate cookie dialogs, CSS animation properties, and media playback state to provide its visible features. It does not intentionally read form values, website passwords, payment details, or editable content. It does not inspect browser cookies, network-response bodies, or the Chrome history database.

Website access could technically expose sensitive page content. The extension code limits its use to the features described here. Page content is not transmitted to or saved by the publisher.

Information stored

Chrome's local extension storage holds enabled HTTP or HTTPS hostnames, feature preferences, grayscale and social-control schedules, and adult-list update status. If the adult-site blocker is enabled, local storage also holds its state, additional domain names, selected regional sources, update timestamps, and short failure statuses. If an optional protection password is chosen, the extension stores a random salt, an iteration count, and a PBKDF2-SHA-256 hash. It does not store the plaintext password.

Chrome locally persists active navigation-blocking rules so they survive a browser restart. Full page URLs, query strings, search terms, page text, video frames, recordings, website credentials, plaintext passwords, blocked-visit events, and chronological browsing history are not stored. Settings do not use Chrome Sync.

Request blocking

When the adult-site blocker is on, Chrome compares top-level navigation requests with a packaged starter list, any hostnames added by the user, and the last successfully downloaded snapshots of selected regional lists. Chrome blocks a match before navigation. The extension does not receive, record, redirect, or transmit the matched address. These rules do not filter advertisements or subresources and cannot cover every adult domain.

Remote services and sharing

The extension has no analytics, advertising SDK, publisher server, cloud model, or remote executable code. When the user selects a regional list and separately grants access, the background worker sends an HTTPS request now and about weekly to a fixed address on raw.githubusercontent.com. The request sends no browsing history, matches, page content, settings, added domains, or password. GitHub and its infrastructure can receive ordinary connection information such as IP address, request time, user agent, and technical logs under their own policies. Deselected sources are not requested.

Responses are treated only as untrusted domain-list data. Quiet Browse uses fixed parsers, rejects malformed or oversized responses, filters selected critical domains, and caps each source below 2,000 installed domains. The independent sources are Jarelllama's Tranco-derived NSFW list (GPL-3.0) and V2Fly domain-list-community (MIT). Coverage labels describe intended audiences, not server locations. The sources are not complete or cryptographically signed by this extension's publisher.

Website hosting

This informational website uses no analytics, advertising, account system, or contact form. It is hosted by GitHub Pages. GitHub may receive connection and technical-log information when a visitor loads the site under GitHub's privacy statement. Support requests use GitHub Issues and are subject to GitHub's privacy practices; users should not include private page content or account information.

User controls and deletion

Users can remove one profile or use the reset control to delete all extension settings and revoke optional host access. Required access to disclosed built-in hosts remains part of the installed manifest, but an inactive or removed profile does not register the page engine. Chrome also lets users disable or uninstall the extension or clear its storage.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Quiet Browse uses locally handled data only to provide or improve its disclosed user-facing features. The publisher does not sell it, use it for advertising or credit decisions, transfer it to data brokers, or permit humans to read it.

Children, adult content, and limits

The adult-site blocker is an optional browsing-friction tool. It does not display or direct users to explicit material. It is not age verification, guaranteed content detection, or a tamper-proof parental-control boundary. The extension and website contain no explicit imagery.

Changes and contact

A future change that adds data collection or another external service requires updated disclosures and appropriate consent before that behavior begins. Questions can be submitted through Quiet Browse support.
