# Quiet Browse public website

This folder is a static, analytics-free website suitable for GitHub Pages.

The public publisher is Constantin Knab. Support is handled through GitHub Issues so no personal email address is published on this site.

Run `python3 scripts/check_publish_site.py` before deployment. Do not submit the Chrome Web Store item until that check passes and all three public pages load over HTTPS without a login.

The free project-site URLs will normally be:

- `https://constantinknab.github.io/quiet-browse/`
- `https://constantinknab.github.io/quiet-browse/privacy.html`
- `https://constantinknab.github.io/quiet-browse/support.html`

Do not add analytics, advertising, tracking pixels, embedded forms, or a third-party chat widget without revising the privacy disclosures and the extension's Chrome Web Store privacy answers.
