Local-first Chrome extension

Calmer pages. Your choices intact.

Quiet Browse reduces high-stimulation browsing with page-by-page navigation, adjustable grayscale, motion limits, social-surface controls, and an optional adult-site blocker.

Version 0.5.2 · Chrome Web Store release pending

One purpose

Reduce high-stimulation and compulsive browsing.

Each feature changes presentation or access friction while preserving ordinary browsing controls wherever practical. Nothing is sold, no account is required, and settings stay on the device.

Steadier pages

Instant screen-by-screen jumps, adjustable grayscale, and reduced decorative motion.

Quieter feeds

Separate controls and schedules for Stories, short video, discovery surfaces, and home feeds.

Optional blocking

Local top-level adult-site blocking with selectable community lists and optional password friction.

Privacy

No analytics. No browsing-history upload.

  • Page structure and limited labels are processed locally for visible features.
  • Chosen hostnames, preferences, schedules, and blocker settings are stored in Chrome's local extension storage.
  • Regional adult-domain lists are contacted only after the user selects them and grants access.
  • No page content, matches, settings, or password is sent to the publisher.

Read the complete privacy policy

Clear limits

Quiet Browse is not a universal dark-pattern detector, medical treatment, age-verification system, precise time-limit system, or tamper-proof parental control. Website interfaces change, community lists can contain false positives or omissions, and Chrome always lets a profile owner disable or uninstall an extension.
