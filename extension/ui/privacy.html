QUIET BROWSE · VERSION 0.5.2

Privacy policy

Effective August 29, 2026. This policy describes the software in this local build. Before public distribution, the publisher must provide their identity and a working support contact on the public policy and store listing.

Purpose

Quiet Browse reduces high-stimulation browsing through reversible presentation controls, social-feed controls, instant paging, optional grayscale by local time, and an optional local adult-site blocker. Built-in profiles operate on the exact disclosed social and shopping hosts; other presentation profiles operate only after you authorize them.

Information processed on your device

The extension uses the current page's host, document structure, static labels and text in candidate cookie dialogs, CSS animation properties, and media playback state to provide its features. It does not intentionally read form values, passwords, payment details, or editable content. It does not inspect network responses, browser cookies, or your browser history database.

Broad website access could technically expose sensitive page content. The code limits its use to the features described here; no page content is transmitted or saved.

Information stored

Chrome's local extension storage holds enabled HTTP or HTTPS hostnames, feature preferences, optional grayscale weekdays, start/end times and amounts, and optional social-surface weekdays and times for each host. If the adult-site blocker is enabled, it also stores its enabled state, additional domain names, selected regional sources, per-source downloaded-domain counts, update timestamps, and short failure statuses. If a password is chosen, a random salt, iteration count, and PBKDF2-SHA-256 password hash are stored. The plaintext password is not stored. Chrome also persists the active dynamic block rules locally so they survive browser restarts. Host and domain preferences can reveal sensitive interests or services.

Full page URLs, query strings, search terms, page text, video frames, recordings, plaintext passwords, blocked-visit events, and a chronological browsing log are not stored. Settings do not use Chrome Sync. Temporary page state needed for undo is discarded when the page closes or reloads. Paused media does not automatically restart when settings are removed.

Request blocking

When Quit Porn is on, Chrome compares top-level navigation requests with the packaged list, any hostnames you add, and the last successfully downloaded snapshots of the regional lists you selected. Chrome blocks a match before navigation. The extension does not receive, record, redirect, or transmit the request address. The rules do not filter subresources or advertisements and cannot cover every adult domain.

Sharing and remote services

This version has no analytics, advertising SDKs, developer server, cloud model, or remote executable code. If you select a regional list, the background worker sends an HTTPS GET request now and about weekly to its fixed address on raw.githubusercontent.com. The request omits credentials and referrer and sends no browsing history, blocked addresses, matches, page content, settings, added domains, or password. GitHub and its infrastructure can receive connection information such as IP address, request time, user agent, and technical logs under their own policies. Deselected sources are not requested.

Responses are treated only as untrusted domain-list data. Quiet Browse uses a fixed parser for each disclosed source, rejects malformed or oversized responses, filters selected critical domains, and installs at most 1,995 US-coverage entries, 1,900 China-coverage entries, and 1,500 Japan-coverage entries. A failed source retains only its own last working rules. Coverage labels describe the intended audience and do not establish domain or server location. The independent sources are Jarelllama's Tranco-derived NSFW list (GPL-3.0) and V2Fly domain-list-community (MIT). They are not complete or cryptographically signed by this extension's publisher. No downloaded JavaScript or other executable content is run.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your controls and deletion

Use Sites & privacy to remove a profile or delete all settings and revoke optional host access. Required access to the exact built-in hosts remains part of the installed manifest but an inactive or removed profile does not register the page engine. If password protection is active, the password is required for extension-UI changes or deletion. There is no recovery. Chrome still permits disabling, uninstalling, or clearing the extension, so the password is a friction tool rather than an enforcement boundary. No account is required.

Permissions

  • activeTab: identifies the current page when you open the toolbar controls.
  • scripting: installs the bundled presentation engine for an enabled host.
  • storage: saves the local preferences and optional adult-blocker configuration described above.
  • alarms: reevaluates scheduled grayscale and social controls about once per minute and schedules selected community-list refreshes about weekly. It cannot wake a sleeping device.
  • declarativeNetRequest: lets Chrome block top-level navigation matching the enabled local adult-domain rules. It is not used for ads, tracking, redirects, or request logging.
  • Required HTTPS host access: enables built-in profiles on the exact listed Instagram, Facebook, TikTok, Amazon, eBay, Etsy, Walmart, Target, Temu, SHEIN US, and AliExpress hosts.
  • Optional HTTP/HTTPS host access: enables automatic presentation controls on another host you explicitly choose. The same optional permission system asks specifically for raw.githubusercontent.com if you select community lists. Host permissions include all ports; HTTP and HTTPS are separate.

Changes and contact

A future change that adds data collection or another external service requires an updated policy and appropriate disclosure and consent. For a published version, use the publisher's verified developer contact on its Chrome Web Store listing. This local build has not been submitted or approved.
