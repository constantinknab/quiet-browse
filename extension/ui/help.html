QUIET BROWSE

Choose how quiet each site should be.

  1. Built-in profiles start enabled on the disclosed social and shopping hosts. Open the toolbar there to change individual controls.
  2. For another ordinary website, click the toolbar icon and choose Enable on this site. Review Chrome's host-access request.
  3. If something looks wrong, choose Show original page for this page or Turn off for this site for a lasting change.
  4. Open Sites & privacy for grayscale schedules, saved profiles, and the optional adult-site blocker.

What the controls do

  • Instant page-by-page navigation: one wheel gesture, Page Up/Down, Arrow Up/Down, Space, or an on-page arrow jumps about one visible screen with a small overlap. Click inside a scrollable panel to page it. Sticky headers are capped so they cannot shrink a jump to half a screen. Choose Normal scroll or hold Alt while scrolling for a bypass. Zoom gestures, text fields, media controls, and touch swipes keep their normal behavior.
  • Grayscale: applies 0–100% grayscale manually or during time windows for that host. Overnight windows use the day they start; equal start/end times mean all day. Overlaps use the highest amount. Times follow the computer's local clock and can be late after sleep. This discourages use without blocking it.
  • Pause decorative loops: pauses recognized infinite CSS animations on decorative or promotional elements. Finite animations, loading indicators, GIFs, canvas animations, and most script-driven animation are left alone.
  • Clarify cookie choices: gives recognized English accept/reject controls equal visual emphasis. It does not decide, click, or set consent.
  • Pause background autoplay: optional; pauses muted autoplay videos without native controls and adds those controls. Click or use the video controls to play deliberately. This feature excludes YouTube.
  • Quiet YouTube previews: hides recognized preview surfaces and ambient effects. It does not guarantee that hidden previews stop loading or decoding.
  • Collapse recommendations: optional; adds a reveal button on supported desktop YouTube watch pages.
  • Hide YouTube video picture: overlays the picture while leaving playback unchanged. The page-only button resets after reload or a YouTube video change. The separate saved preference automatically reapplies the cover after both events; page-only Show picture temporarily reveals the current video without changing that preference. The cover hides visual information, including text embedded in the video. Native player controls, including mute, and captions are intended to remain available above it. Recognized ads are uncovered; picture-in-picture is unchanged.

Social controls

Instagram, Facebook, and TikTok show separate switches for Stories, short-video hubs, Explore/Discover, and the home feed. Checked means hidden. TikTok's first page is both a short-video stream and its home feed, so either checked control stops it. Messages, profiles, searches, and direct post or video URLs remain available. On a direct item or conversation, supported continuation recommendations are removed so the page stops instead of becoming another feed. Long content, comments, and conversations can still scroll. Website changes, languages, experiments, and signed-in layouts may break selectors.

Quit porn

This optional setting blocks top-level navigation to a packaged adult-domain starter list and hostnames you add. If you separately authorize weekly community updates, Quiet Browse downloads only the US-coverage, China-coverage, and Japan-coverage lists you select through GitHub's raw-content host now and about weekly. Each source is capped below 2,000 installed domains. Invalid or unexpectedly sized updates are rejected, and each source keeps its own last working rules. The lists are independent and unsigned, so false positives, omissions, source compromise, and outages remain possible. The request sends no browsing history or settings, although GitHub receives ordinary connection information such as IP address and request time. Source and license details appear in the privacy policy.

A password can be handed to a trusted person and is stored only as a salted hash. There is no recovery. The feature cannot cover every site or prevent disabling/uninstalling the extension, clearing its data, or using another browser or profile.

Limits and recovery

This is an early release, not a universal dark-pattern detector, accessibility certification, flashing-content safety filter, complete content filter, parental control, or precise time-limit system. Test sites you rely on. Cross-origin embedded frames, closed shadow trees, custom scrollers, fullscreen surfaces, and browser-protected pages may be outside this version's coverage.

The extension never automatically restarts a paused video when you undo changes. Use the site's play control. If you disable or uninstall the whole extension through Chrome, reload an affected page after saving unfinished work to remove any remaining injected changes.

For automatic next-video playback, use YouTube's own Autoplay switch. Quiet Browse does not change account settings.

Remove a site or everything

Sites & privacy includes Remove profile/site and Delete all settings. These delete stored preferences and revoke optional host access. Required access to built-in hosts remains in Chrome until uninstall, but removed profiles do not run. A protected adult blocker requires its password for these UI actions.
