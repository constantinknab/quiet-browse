OPTIONAL LOCAL BLOCKER

Quit Porn

Blocks top-level navigation to a small packaged starter set, your additions, and any regional community lists you select. Lists update about weekly and remain below 2,000 installed domains each. Coverage labels describe the audience a preset is meant to help; they do not claim where a domain or server is located.

Give the password to a trusted person if you want changes to require their help. Quiet Browse stores a salted PBKDF2 hash, never the plaintext password. This is friction, not tamper-proof parental control.

Reset

Deletes all saved site preferences, schedules, blocker data, dynamic rules, and optional host access. Built-in host declarations remain part of the installed extension and are restored with their defaults after reinstall.

Privacy without an account

Quiet Browse inspects page structure locally. It stores chosen hostnames, feature preferences, grayscale and social-surface schedules, and adult-list update status in Chrome’s local extension storage. There is no analytics, browsing-history log, cloud AI, cookie access, or video capture.

The only extension-initiated external requests are the regional list downloads you explicitly select. Read the full privacy disclosure.
