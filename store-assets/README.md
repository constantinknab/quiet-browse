# Chrome Web Store graphic assets

Generated from the original Quiet Browse icon and color system:

- `store-icon-128.png` — required 128×128 store icon.
- `small-promo-440x280.png` — required small promotional tile.
- `marquee-1400x560.png` — optional marquee promotional tile.

Regenerate them with `python3 scripts/make_store_assets.py`.

The screenshot slots are deliberately not prefilled. Chrome Store screenshots must show the actual extension running in Chrome, not the local simulated fixture. Follow `docs/STORE-SUBMISSION-GUIDE.md` for the exact five-shot sequence.
