# Security policy

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/constantinknab/quiet-browse/security/advisories/new).

Do not disclose an unpatched vulnerability in a public issue. Do not include passwords, authentication cookies, private messages, payment information, or other sensitive page content in any report.

The currently supported release is listed in `extension/manifest.json`. Security fixes will be released as a new packaged version after verification.
